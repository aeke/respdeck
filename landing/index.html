A FEW THINGS TO KNOW

Clear by design.

Is RESPdeck free and open source?

Yes. RESPdeck is released under the MIT license. Use it, inspect it, and contribute on GitHub.

Does the live demo connect to my Redis?

No. The hosted demo uses synthetic data in your browser. Edits reset on reload. Run RESPdeck on your own infrastructure for real connections.

What is supported today?

The initial release candidate supports standalone Redis and six core data types. Cluster, Sentinel, SSH tunnels, RedisJSON modules, and multi-user access are outside the current release.

Does it send telemetry?

RESPdeck includes no analytics or telemetry. The GitHub Pages demo is hosted by GitHub; real Redis connections stay on your self-hosted server.
